# 🔐 SOCKS5 Proxy Manager

A robust, Docker-based SOCKS5 proxy server with a modern web management interface. This tool allows you to transform any Linux machine into a fully-managed SOCKS5 proxy server with user authentication, real-time statistics, and automated quota enforcement.

## 🚀 Features

### Core Proxy Functionality
- **High-Performance SOCKS5:** Built on the reliable `3proxy` engine.
- **Custom Port:** Uses port `3389` by default to bypass restrictive firewalls (commonly allowed for RDP).
- **Authentication:** Secure username/password authentication for every proxy user.
- **Traffic Shaping:** Per-user bandwidth limiting (KB/s).
- **Access Control:** Block specific domains or IP addresses for individual users.
- **DNS Reliability:** Integrated DNS resolution for consistent domain blocking.

### Management Dashboard
- **User Management:** Create, edit, enable/disable, and delete proxy accounts via a modern UI.
- **Real-time Stats:** Monitor bandwidth usage per user for the current day.
- **Automated Quotas:** Set daily data caps (MB); the system automatically disables users who exceed their limit.
- **Activity Logs:** Detailed connection logs including source/destination IPs and domains.
- **System Monitoring:** Track host CPU usage, memory, load average, and uptime directly from the dashboard.
- **Security:** Change admin credentials and secure the interface with SSL/HTTPS.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, Vanilla JavaScript (Material Design inspired).
- **Backend:** Python Flask, PostgreSQL.
- **Proxy:** 3proxy.
- **Orchestration:** Docker Compose.

## 📋 Prerequisites
- Docker and Docker Compose.
- Linux-based host (recommended).
- Open ports: `80`, `443` (Web), `3389` (SOCKS5).

## 🚀 Quick Start

1. **Clone the repository:**
   ```bash
   git clone <your-repo-url>
   cd SOCKS5-Proxy-Manager
   ```

2. **Start the services:**
   ```bash
   docker-compose up -d --build
   ```

3. **Access the dashboard:**
   - URL: `https://your-server-ip`
   - Default Username: `admin`
   - Default Password: `admin123`
   - *⚠️ Note: Self-signed certificates are generated by default. You may see a browser warning.*

4. **Change the admin password immediately after logging in!**

## 🔧 Configuration

### Ports
- **Web Interface:** 80 (HTTP) & 443 (HTTPS)
- **SOCKS5 Proxy:** 3389

### SSL Certificates
Placeholder certificates are included in `frontend/ssl/`. For production, replace `cert.pem` and `key.pem` with your own (e.g., from Let's Encrypt).

## 📝 Usage

### Connecting to SOCKS5
Use the credentials created in the dashboard:
- **Server:** `your-server-ip`
- **Port:** `3389`
- **Username:** `your-username`
- **Password:** `your-password`

**Test connection with curl:**
```bash
curl -v -x socks5h://username:password@your-server-ip:3389 https://google.com
```
